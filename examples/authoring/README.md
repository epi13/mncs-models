# Numerical argument examples

`initial.args.json` supplies five weights and four features to native
`mncs.models.trial::score_authored`. `compact-infer.args.json` supplies a full
compact Model and Signal to `mncs.models.micro::infer`.

Use the admitted compiler's `mncs call` entrypoint with `--library src` and the
matching source/module/function. Change argument numbers without changing inference
code. These are mechanical data examples; see docs/DIRECT_WEIGHT_TRIAL.md for the
unconducted controlled-trial protocol and custody requirements.
