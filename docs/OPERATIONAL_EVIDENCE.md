# Read-only residual-utility evidence audit

Finding: the inspected sources do not provide a defensible real-data training/
held-out cohort. No real-data model was fitted or evaluated. This is a bounded
inspection, not a claim that no usable evidence exists anywhere in MNCS.

## Sources actually examined

Source paths, observed heads, file hashes and HEAD-blob agreement are recorded in
`outputs/residual/source-audit.json`. The live read-only Forge MCP receipt inventory
and status subset are retained in `operational-audit.json`. No job was launched,
service restarted, raw Store opened, or paused tooling checkout modified.

- Current selected Forge context: zero identity-bound execution receipts, no active
  job, zero reported resource-exhaustion events, Store generation zero, and an
  unresolved Language Service ingress timeout. Status UNKNOWN is not a verified
  failure cause, and the timeout has no independently confirmed diagnostic resolution
  in this read surface.
- Environment resource-feedback live evaluation (2026-10-13): a real System Monitor
  sample was retained and verified through the Automation input path, but execution
  identities were explicit sentinels. The deterministic decision was UNKNOWN because
  Forge execution records were unavailable. The record explicitly says no real
  receipt-correlated admission or subsequent compiler execution was proven.
- Compiler resource-feedback frontier and Forge readiness records: zero matching
  receipts, missing linked execution/subject/peak measurements. Their fixture tests
  verify predicate behavior, not predictions on real jobs.
- Caller-interruption reconciliation record: verified durable readback/idempotent
  retry already resolves the missing-response condition deterministically. It does
  not justify a model guessing whether publication occurred.
- Doctor encoding migration record: UTF-8/BOM/newline findings are already classified
  by native deterministic policy with exhaustive fixture parity. This is not a
  residual uncertainty to make probabilistic.
- Environment capability-intelligence documentation explicitly distinguishes recorded
  status/no-failure-reported from independently verified outcomes and says agent
  need, fulfillment, causality and intervention burden remain unestablished.

Only bounded public repository evidence and the configured read-only Forge context
were inspected. The audit does not infer that other contexts/stores have no receipts
or that old source revisions describe every current runtime. No historical success
following an intervention is treated as proof that the intervention caused success.

## Most concrete candidate, not yet an eligible learning task

Potential question: after authoritative readiness, exact artifact/test-selection
checks and existing resource-headroom rules have run, will a particular next bounded
compiler verification finish within its declared resource envelope?

The current absence of receipts/measurements is an infrastructure prerequisite,
not uncertainty a neural predictor should fill. Retain UNKNOWN and obtain missing
authoritative observations. Even with observations, the candidate must demonstrate
that the actual deterministic path leaves an uncertainty or incurs avoidable burden;
that has not been demonstrated by this audit.

Relevant existing baseline is Automation's resource-headroom predicate: fresh host
memory, unique Forge execution and subject identity, declared envelope, measured
cgroup peak, estimated requirement/measurement scaling and minimum headroom. Do
not remove any of those inputs to manufacture a weak baseline. Compare an improved
same-input rule where defensible, including exact workload/envelope matching or
conservative prior-observation bounds if the owner considers them reliable.

## Least additional evidence for an honest next experiment

Existing owners could retain these references during ordinary authorized work,
without a model controlling operations:

1. One pre-decision feature snapshot, source observation times, decision time, event/
   execution/subject identities, exact workload/test selection and baseline rule
   version, decision and reason. Explicitly retain which cases were already resolved.
2. A later matching Forge completion/verification receipt and independently observed
   resource outcome: successful completion, timeout, actual exhaustion, cancellation
   or test failure. Avoid inferring OOM merely from a generic nonzero exit code.
3. Pre-launch System Monitor/Doctor/worker observations aligned to the same execution
   context. Measurements from that target job's completed execution cannot become
   pre-launch features. Earlier jobs' measurements may be features only when their
   availability is documented before the target decision.
4. Multiple independent event groups with meaningful positive and negative outcomes,
   no sentinel identities, rights/use authorization, a chronological/event-grouped
   split, and a sealed held-out cohort managed outside the author's access scope.
5. Actual diagnostic actions, agent escalation/intervention time and final verified
   outcomes if environmental benefit is to be claimed. Predictive accuracy alone
   does not reveal what an unchosen action would have done.

Reuse Forge receipts, System Monitor samples, Environment observation/projection
references and existing burden records. Do not introduce a parallel data service.
Capturing these is a proposed natural extension of ordinary authority-owned records,
not an implemented tooling change in this phase.

## Smallest next comparison

Start with existing deterministic Path A and an improved deterministic Path B only
if it is justified. Add one 5–20 parameter single-view residual predictor (Path C)
only after a labeled residual cohort exists. Add complementary views (Path D) when
they supply independent pre-decision information and improve a same-input comparison;
use deterministic fusion as a baseline. A composed Path E must earn its extra cost.

Measure conditional residual accuracy, coverage, critical misses and false routing,
plus the full established/residual workload and actual resource/burden quantities.
Historical observational comparisons are predictive evidence, not causal savings.
A later read-only shadow evaluation needs separate authorization/custody; it still
must not grant an experimental model recovery or scheduling authority.
